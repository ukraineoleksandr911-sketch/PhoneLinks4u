# PhoneLinks4u: концепт сайту (головна + меню)

Статичний сайт без збірки за ТЗ для магазину ремонту телефонів і аксесуарів. Дизайн із ТЗ: білий і світло-сірий фон, темно-синій hero й футер, один синій акцент #2563EB, шрифти Manrope (заголовки) і Inter (текст), радіуси 12-16 px, м'які тіні. Шрифти лежать у `assets/fonts`.

## Структура

```
index.html                 Головна: 9 блоків з розділу 7 ТЗ (hero, популярні ремонти, калькулятор,
                           чому ми, аксесуари, як проходить ремонт, відгуки, локація, FAQ)
repair/ accessories/ services/ warranty/ contact/   Сторінки меню (index.html у кожній)
assets/css/tokens.css      Кольори, шрифти, відступи (генерується з конфігу)
assets/css/base.css        Компоненти й розкладка
assets/js/config.js        Години роботи, марки, моделі й ціни калькулятора
assets/js/site.js          Меню, випадні списки, статус Open/Closed, каруселі
assets/js/calc.js          Калькулятор ремонту, фільтр аксесуарів, форма запису
robots.txt                 Disallow: / (демо)
.nojekyll                  Потрібен для GitHub Pages
```

## Перегляд

- Локально: двічі клікніть `index.html`, або в цій папці `python -m http.server 8000` і відкрийте http://localhost:8000
- GitHub Pages: Settings, Pages, Deploy from branch, `main`, `/ (root)`.
- Cloudflare Pages: підключіть репозиторій, build command порожня, output directory `/`.

## Що потрібно підтвердити або замінити

- **Ціни й терміни калькулятора вигадані** для демонстрації. Вони в `clients/phonelinks4u.json` (`faults`, `prices` по трьох класах моделей). Під ними на сайті є позначка «Example prices».
- **Четвер 9:00-17:00** у Google відрізняється від інших днів. Перевірте, чи це не помилка в профілі.
- **WhatsApp:** невідомо, чи є він на цьому номері.
- Жовті підкреслені тексти в дужках (`[add terms]`, `[email address]`, політики гарантії, деталей і даних) це плейсхолдери.
- Товари аксесуарів і їхні ціни приклади. У Google згадано, що в магазині є вибір аксесуарів.
- Кошик і «Sign in» у шапці та в мобільній панелі показують підказку «part of the full site». Особистий кабінет, кошик, оплата й адмінка з ТЗ тут не реалізовані.
- На сторінках `noindex`. Для бойового запуску прибрати його і вміст `robots.txt`.
- Репозиторій краще тримати приватним, бо в ньому реальна назва й телефон бізнесу.
